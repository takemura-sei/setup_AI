# setup_AI

Claude Code をはじめとした AI エージェント向けの拡張機能（Skills / サブエージェント / MCP設定 など）を作成・蓄積・管理していくリポジトリです。

## このリポジトリについて

使えそうな拡張機能を思いついたら、どんどん作ってここに追加していきます。
中身は今後継続的に増減・変化していく想定のため、構成も流動的です。

## 管理する対象

- **Claude Code Skills** — `.claude/skills` 配下に置くようなスキル定義
- **サブエージェント定義** — `.claude/agents` 配下のカスタムエージェント
- **MCPサーバー設定** — 外部ツール連携のための設定・メモ
- **その他のAIエージェント拡張機能全般** — hooks や `settings.json` のスニペットなど

## ディレクトリ構成

現時点ではまだ雛形ディレクトリは作っていません。内容が増えてきたタイミングで `skills/`, `agents/` などのディレクトリに整理していく予定です。

## 今後の運用イメージ

- 便利だった skill / agent / 設定を随時追加していく
- 各拡張機能には簡単な説明（何をするものか・使い方）を添える
