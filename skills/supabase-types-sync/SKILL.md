# supabase-types-sync

## 何をするものか

Supabaseをスキーマ管理（マイグレーション運用）の起点とし、Prismaなど他のORMは使わない構成のプロジェクト向けに、マイグレーション追加後の型同期作業を一括で行うSkill。

1. Supabase MCPサーバーの `generate_typescript_types` で最新のデータベース型を生成する
2. 生成結果と既存の型定義ファイル（例: `shared/types/database.ts`）を比較し、差分をユーザーに提示した上で反映する
3. 差分（追加・削除・変更されたテーブル/カラム）の影響が及びそうなマッパー関数・ドメイン型変換処理を検索し、更新が必要そうな箇所を一覧化して提案する

本Skillはあくまで「型の再生成・反映・影響箇所の洗い出し」までを担当し、マッパー関数自体の修正は提案に留める（実装はユーザー判断、または別途 `issue-implementer` 等に委ねる）。

## 呼び出しタイミング

- 「Supabaseの型を同期して」「マイグレーション追加したのでdatabase.tsを更新して」と言われたとき
- `supabase/migrations` にマイグレーションを追加・変更した直後
- スキーマ変更のPRを作る前に、型定義が最新か確認したいとき

## 前提条件

- 対象プロジェクトがSupabaseをDBに使い、スキーマはSupabase側（マイグレーション）で管理している（Prisma等のORMでスキーマを管理していない）
- Supabase MCPサーバーに接続済みで、対象プロジェクトのSupabaseプロジェクトを操作できる状態であること。接続がない、または対象プロジェクトが特定できない場合は、その旨をユーザーに伝えて中断する

## 実行手順

1. **対象プロジェクトの特定**: 対象リポジトリの `supabase/config.toml` や `.env` 等から、操作対象のSupabaseプロジェクト（project ref）を確認する。複数プロジェクト（ローカル/本番等）が存在し得るため、不明な場合はユーザーに確認する
2. **既存の型ファイルの検出**: プロジェクト内で型定義の出力先を検索する（例: `shared/types/database.ts`）。プロジェクトごとにパス・ファイル名が異なり得るため、`adding-a-feature.md` 等のドキュメントや既存のimport文から実際のパスを確認する
3. **型の再生成**: Supabase MCPサーバーの `generate_typescript_types` を呼び出し、最新のデータベース型定義を取得する
4. **差分確認**: 取得結果と既存ファイルの内容を比較し、差分（テーブル・カラムの追加/削除/型変更）をユーザーに提示する
5. **反映**: ユーザー確認の上で、既存の型ファイルを再生成結果で上書きする（差分がなければ何もしない旨を報告する）
6. **影響範囲の洗い出し**: 差分に含まれるテーブル・カラムをキーに、`shared/types/` 配下のドメイン型やマッパー関数（DB行→ドメインオブジェクト変換など）を検索し、更新が必要そうな箇所をファイル・行付きで一覧化する。この時点では修正コードの提示に留め、ファイルの書き換えは行わない

## ユーザー確認が必要な操作

- 既存の型定義ファイル（`shared/types/database.ts` 等）への上書き
- 対象のSupabaseプロジェクトが複数候補あり一意に特定できない場合の選択

## 制約・注意点

- 本Skillが自動で修正するのは型定義ファイルのみ。マッパー関数・ドメイン型変換処理そのものの修正は提案に留まり、適用はユーザー判断に委ねる
- マイグレーションの作成・適用自体は本Skillの対象外。既にマイグレーションがSupabase側に適用済みであることが前提
- Supabase MCPサーバーに接続していない環境（Supabase CLIのみのローカル環境など）では `generate_typescript_types` が使えないため、その場合は `supabase gen types typescript` 等のCLI代替手段が必要になる旨をユーザーに伝える

## 使用例

```
supabase-types-syncでtyping-gameの型を同期して
```

→ `generate_typescript_types` で最新の型を取得し、既存の `shared/types/database.ts` との差分を提示した上で反映、影響を受けそうなマッパー関数の一覧を提案する。
