# claude-md-sync

## 何をするものか

CLAUDE.mdの「技術スタック」欄・コマンド一覧は、依存追加のたびに手動で更新する運用が前提になっており、`package.json` の実態と乖離しやすい。本Skillは以下を行う。

1. `package.json` の `dependencies` / `devDependencies` を読み取り、主要なライブラリ・フレームワーク（バージョンも含む）を抽出する
2. `package.json` の `scripts` を読み取り、`npm run` で実行できるコマンド一覧を抽出する
3. CLAUDE.md内の技術スタック欄・コマンド一覧のセクションをパースし、1・2で抽出した実態と突き合わせる
4. 差分（CLAUDE.mdに記載がないのに `package.json` にある依存/コマンド、逆にCLAUDE.mdにあるが `package.json` から消えている依存/コマンド）を一覧化し、更新案（追記・削除案）をユーザーに提示する

本Skillはあくまで「差分の検出と更新案の提示」までを担当し、CLAUDE.mdの書き換えはユーザー確認を経てから行う。

## 呼び出しタイミング

- 「CLAUDE.mdを同期して」「package.jsonとCLAUDE.mdの技術スタックがずれてないか確認して」と言われたとき
- 依存パッケージの追加・削除・`scripts` の変更を含むPRを作る前
- 定期的な棚卸し（`weekly-digest` 等と組み合わせた運用）の一環として

## 前提条件

- 対象プロジェクトのルートに `package.json` と `CLAUDE.md` が存在すること
- CLAUDE.mdに技術スタック・コマンド一覧に相当するセクションが存在すること（見出し名はプロジェクトごとに異なり得るため、事前に確認する）

## 実行手順

1. **対象ファイルの特定**: 対象リポジトリの `package.json` と `CLAUDE.md` のパスを確認する。モノレポ構成の場合は、どの `package.json` を基準にするかユーザーに確認する
2. **package.jsonの読み取り**: `dependencies` / `devDependencies` の一覧（パッケージ名・バージョン）と `scripts` の一覧（コマンド名・実行内容）を抽出する
3. **CLAUDE.mdの読み取り**: 技術スタックを記載しているセクション、コマンド一覧を記載しているセクションを特定し、そこに列挙されているパッケージ名・コマンド名を抽出する。見出しがどれに該当するか自明でない場合はユーザーに確認する
4. **突き合わせ**: 双方の一覧を比較し、以下の観点で差分を洗い出す
   - `package.json` にあるが CLAUDE.md に記載がない依存・コマンド（追記候補）
   - CLAUDE.md にあるが `package.json` から消えている依存・コマンド（削除候補、既に使われていない可能性がある）
   - バージョン表記がある場合、記載バージョンと実際のバージョンの差異
5. **更新案の提示**: 差分をファイル・セクション単位で一覧化し、追記/削除の具体的な文面案を提示する。差分がなければ「同期済み」と報告して終了する
6. **反映**: ユーザーが更新案を承認した場合のみ、CLAUDE.mdを編集する

## ユーザー確認が必要な操作

- CLAUDE.mdへの実際の書き込み（追記・削除）
- モノレポ等で基準とする `package.json` が一意に特定できない場合の選択
- CLAUDE.md内のどのセクションが「技術スタック」「コマンド一覧」に該当するか自明でない場合の確認

## 制約・注意点

- 本Skillは `package.json` に現れる依存関係・`scripts` のみを対象とする。CLAUDE.md内の技術スタックの説明文（選定理由など）の妥当性までは検証しない
- パッケージ名の表記揺れ（例: `Nuxt` と `nuxt`）は簡易的な正規化のみ行う。判定に迷う場合は差分として提示しユーザー判断を仰ぐ
- CLAUDE.mdの書き換えは常に差分提示→ユーザー承認を経てから行い、無断で上書きしない

## 使用例

```
claude-md-syncでpokemon_apply_v2のCLAUDE.mdを同期して
```

→ `package.json` の依存関係・`scripts` とCLAUDE.mdの技術スタック・コマンド一覧を突き合わせ、差分（追記候補・削除候補）を一覧化して提示する。承認後にCLAUDE.mdへ反映する。
